# App icon assets

The 25 SVG files in this directory were downloaded from the [`simple-icons`](https://github.com/simple-icons/simple-icons) package through jsDelivr, pinned to version `16.27.1`.

- 24 icons are used in the landing-page compatibility train.
- `apple.svg` is used as the source reference for Apple-branded download controls.
