# App icon assets

The 27 SVG files in this directory were downloaded from the [`simple-icons`](https://github.com/simple-icons/simple-icons) package through jsDelivr, pinned to version `16.27.1`.

- 24 icons are used in the landing-page compatibility train.
- `apple.svg`, `google.svg`, `notion.svg`, and `nvidia.svg` also appear in the product-owner-confirmed workplace proof row.
- Product names and logos are trademarks of their respective owners.
- Compatibility logos indicate application compatibility only. Workplace logos identify where individual users work; neither use implies partnership or endorsement.
