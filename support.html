Quick start

  1. Launch WhisprTyper. It appears in the macOS menu bar rather than the Dock.
  2. Follow the setup guide to allow Microphone and Accessibility access.
  3. Hold the bare Control key to dictate, then release it to finish. Push-to-talk is enabled by default; the configurable global shortcut defaults to Control–Option–Space.
  4. The pill changes from its waveform to a spinner while WhisprTyper finalizes and attempts to return the transcript to the supported editable field that was active when recording began.

First model download

The default WhisperKit engine downloads an approximately 626 MB speech model the first time it is used. Keep WhisprTyper open and connected until preparation finishes. The model is cached locally; subsequent transcription works on-device and can run offline.

Permissions

  • Microphone: System Settings → Privacy & Security → Microphone.
  • Accessibility: System Settings → Privacy & Security → Accessibility. This lets WhisprTyper identify and return text to supported editable fields.
  • Speech Recognition: requested only if you explicitly select Apple System Speech. The default WhisperKit engine does not request it.

After changing a permission, return to WhisprTyper; its setup and settings screens refresh the status automatically.

Troubleshooting

  • No text appears: confirm Accessibility is enabled, then retry in a supported editable field. Password fields are intentionally refused.
  • Model is still preparing: allow the initial download to finish. Quit WhisprTyper only if you want to cancel preparation.
  • Shortcut conflict: open Settings and record another shortcut.
  • Need your last transcript: after a failed insertion, use Copy Last Transcript or Retry Last Insertion before quitting. Retry targets the original failed destination and is unavailable after a successful insertion. Recovery is memory-only and clears on quit.
